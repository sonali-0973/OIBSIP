# Task 3: Cleaning House Prices Data

## Overview

This project is part of the **Oasis Infobyte Data Analytics Internship (OIBSIP)**. The objective of this task is to demonstrate professional-level data cleaning skills by transforming the House Prices dataset into a clean and analysis-ready dataset.

The cleaning process was performed using **Python, Pandas, NumPy, and Jupyter Notebook**, with the major cleaning decisions documented throughout the notebook.

## Dataset

The project uses the **House Prices dataset**, which contains **1,460 rows and 81 columns** describing residential properties.

The main files in this project are:

* `House Prices.csv` — Original dataset
* `House Prices Cleaned.csv` — Cleaned dataset generated by the notebook
* `Task3_House_Price_prediction.ipynb` — Jupyter Notebook containing the complete data-cleaning process

## Tools and Technologies

* Python

* VS Code

## Data Cleaning Process

### 1. Load and Inspect the Dataset

The dataset is loaded using Pandas and inspected for:

* Dataset shape
* Column names
* Data types
* Initial records
* Overall dataset information

### 2. Data Quality Report

A data quality report was created to identify:

* Missing values per column
* Missing-value percentages
* Data types
* Number of unique values
* Duplicate rows

Numerical columns were also examined using minimum, maximum, quartiles, and median values to identify potential value-range anomalies.

### 3. Missing Data Handling

Missing values were handled according to the meaning and type of each variable rather than using one method for all columns.

#### Categorical Features

Missing values in features such as:

* `Alley`
* `MasVnrType`
* `BsmtQual`
* `BsmtCond`
* `BsmtExposure`
* `BsmtFinType1`
* `BsmtFinType2`
* `FireplaceQu`
* `GarageType`
* `GarageFinish`
* `GarageQual`
* `GarageCond`
* `PoolQC`
* `Fence`
* `MiscFeature`

were replaced with `"None"` because missing values represent the absence of that feature.

#### Numerical Features

Feature-related numerical columns such as:

* `MasVnrArea`
* `BsmtFinSF1`
* `BsmtFinSF2`
* `BsmtUnfSF`
* `TotalBsmtSF`
* `BsmtFullBath`
* `BsmtHalfBath`
* `GarageCars`
* `GarageArea`

were filled with `0` where the absence of the feature represents zero.

`LotFrontage` was filled using the median value within each `Neighborhood`, with the overall median used as a fallback.

`GarageYrBlt` was set to `0` for houses without a garage, with the median used for remaining missing values.

The missing value in `Electrical` was handled using the column mode.

### 4. Duplicate Removal

The dataset was checked for duplicate rows. Duplicate records were removed using Pandas `drop_duplicates()`.

The original House Prices dataset contained **no duplicate rows**, so no records were removed during this step.

### 5. Data Standardisation

Categorical columns were checked for inconsistent formatting.

The cleaning process:

* Removed leading and trailing whitespace.
* Converted empty strings to missing values.
* Preserved meaningful dataset-specific categorical codes such as `RL`, `RM`, `Pave`, `Gd`, `TA`, and `Normal`.

The dataset does not contain actual date columns requiring conversion to `datetime`. Year-related variables such as `YearBuilt`, `YearRemodAdd`, `GarageYrBlt`, and `YrSold` were retained as numerical year values.

### 6. Data Type Correction

Several data types were corrected based on the meaning of the variables:

* `Id` was converted to **string** because it is an identifier.
* `MSSubClass` was converted to **string** because it represents a housing classification code.
* `SalePrice` was converted to **float** because it represents a monetary value.

A before-and-after data type comparison was created to document these changes.

### 7. Outlier Detection

The **Interquartile Range (IQR)** method was used to identify potential outliers in numerical columns.

For each numerical column, the notebook calculates:

* Q1
* Q3
* IQR
* Lower bound
* Upper bound
* Number of detected outliers

Important numerical variables such as `LotArea`, `GrLivArea`, `TotalBsmtSF`, `1stFlrSF`, `GarageArea`, and `SalePrice` were also inspected for their minimum and maximum values.

### 8. Outlier Handling Decision

The detected IQR outliers were not automatically deleted.

In a house-price dataset, unusually large houses, lots, garages, or sale prices can represent legitimate properties. Removing all statistical outliers could therefore remove valid observations and introduce bias.

The identified outliers were reviewed and retained when they represented plausible real-world house values.

### 9. Value Validation

Additional checks were performed for potentially invalid values, including:

* Negative `LotArea`
* Negative `SalePrice`
* Negative `GrLivArea`
* Invalid `MoSold` values
* Invalid `YrSold` values

### 10. Before vs. After Comparison

A summary table was created to compare the dataset before and after cleaning using:

* Row count
* Total missing values
* Duplicate rows

A separate comparison was also created to show changes in data types.

### 11. Final Data Quality Check

The cleaned dataset was checked again for:

* Number of rows
* Number of columns
* Remaining missing values
* Remaining duplicate rows
* Final data types

### 12. Save the Cleaned Dataset

The final cleaned dataset was exported as:

```text
House Prices Cleaned.csv
```

The saved CSV file was then loaded again to verify that the cleaning process and file export were successful.
